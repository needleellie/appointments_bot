# Beauty Bot 💅

Небольшой Telegram-бот для записи в салон красоты.

Проект сделан на Python и `pyTelegramBotAPI`. Бот умеет:
- показывать услуги;
- предлагать свободные дни и время;
- сохранять записи в JSON;
- сохранять имя клиента;
- принимать отзывы.

## Как запустить

1. Установите зависимости:

```bash
pip install -r requirements.txt
```

2. Создайте переменную окружения `BOT_TOKEN` с токеном своего Telegram-бота.

3. Запустите:

```bash
python main.py
```

## Команды

- `/start` — приветствие;
- `/make_appointment` — запись на услугу;
- `/set_name` — сохранить имя;
- `/make_review` — оставить отзыв.

## Хранение данных

Для простоты данные хранятся в `user_data.json`. Для небольшого учебного проекта этого достаточно, а отдельный модуль `json_core.py` отвечает за чтение и сохранение файла.

> Токен бота не хранится в коде. Перед публикацией проекта на GitHub лучше всегда проверять, что секреты не попали в репозиторий.
